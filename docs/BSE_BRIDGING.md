# 銜接性試驗評估（BSE）審查門檻

系統的申請類型「**銜接性試驗評估（BSE）**」（`bse_application`，15 項）依附錄E 查檢表逐項建立，另附 BSE 自我評估報告與銜接性試驗本身。新藥查驗登記範本中的「M1 銜接性試驗評估（BSE）」項目也已連結到此範本。

> 本文件為法規資料整理，不構成正式法規意見。

## 是否須申請（審查準則第22條之1）

- **應申請**：新成分新藥、屬新成分之生物藥品，以及其他經公告應申請者。
- **例外**：已在我國進行對國人具代表性之臨床試驗，且能提供東亞人種藥動資料者。
- **免申請**：經認定符合「小兒或少數嚴重疾病藥品審查認定要點」者，以及細胞治療、基因治療製劑。
- **申請時點**：可在查驗登記前申請，也可與查驗登記同時申請。
- **評估結果**：
  - 免除者：查驗登記免附銜接性試驗資料，但療效與安全性仍須有充足的臨床資料。
  - 不得免除者：先送銜接性試驗計畫書，審查同意後執行，完成後將報告送備查。
- **學名藥 5 年規定**：國內完成銜接性試驗並核准之新藥，發證 5 年內，相同成分、劑型、劑量的學名藥須附相同標準之國內銜接性試驗報告。

## 範本結構

### 附錄E 查檢表（11 項）

| 項目 | 主要門檻 |
|------|---------|
| 申請前確認 | 是否須申請、免申請條件、申請時點 |
| 附錄E 查檢表 | 逐項勾「有／無」並填冊數頁數；依序提供整合摘要 |
| Ⅰ 臨床試驗現況 | 完成、執行中、預計之全部試驗；台灣與亞洲 stand-alone 試驗及 MRCT 特別註明 |
| Ⅱ 完整臨床數據資料（CCDP） | CTD M2（Phase I～III，含 PK）與仿單擬稿，必要時 M5；部分選用者附完整 CSR；NCE-2 分類引用文獻；中文仿單擬稿或中文適應症與用法用量 |
| Ⅲ 東亞族群資料 | 中日韓可代表我國，印度、中東等不可；歐美亞裔考量外因性；BDP 四種來源；MRCT 列出各國人數與比例 |
| Ⅳ 東西方比較：藥動／藥效 | 東亞 vs 非東亞優先；含活性代謝物；試驗內、跨試驗比較條件；pop-PK（東亞 >10%、提供模擬參數）；以目標病人、最大劑量、穩態為重；不宜體重標準化；生物製劑比較 ADA，PEG 藥品比較抗 PEG 抗體 |
| Ⅳ 東西方比較：療效／安全 | 東亞 vs 非東亞、東亞 vs 整體（ITT）；基準特徵與曝藥時間；主要與關鍵次要指標；抗生素附國內 MIC，抗病毒藥評估流行株；安全性以 subject-time 校正 |
| Ⅴ 12 項族群敏感性自我評估 | 逐題「是／否／未知」附依據；不能取代Ⅲ、Ⅳ |
| Ⅵ 上市後安全性 | PSUR／PBRER 摘要與完整報告；未上市者標「不適用」 |
| Ⅶ 上市滿五年之新成分新藥（依適用性） | 111.09.30 第1111407703號公告適用者：國內試驗准予執行公文、臨床試驗資訊網查詢結果 |
| Ⅷ 自我總結評估 | 疾病與藥品背景、BDP 人數比例、藥動與臨床差異的臨床意義、利害權衡、是否須執行銜接性試驗之結論 |

### BSE 自我評估報告（1 項）

獨立撰寫的整合性摘要，內容包括：
- 作用機轉、適應症與用法用量、疾病背景。
- 我國與歐美的疾病成因、流行病學、診斷、標準治療及醫療行為差異。
- 各國送件與核准現況。
- 試驗列表；劑量尋找試驗與樞紐試驗摘要。
- 項目Ⅲ～Ⅵ、12 項自我評估、總結。

### 銜接性試驗（3 項，皆為「依適用性」）

這三項只有在 TFDA 評估「不得免除」時才需要；沒被要求時標記「不適用」並註明 BSE 評估結果。

| 項目 | 主要門檻 |
|------|---------|
| 銜接性試驗計畫書 | 試驗類型依族群敏感性決定：不需試驗、藥理指標試驗、或對照設計臨床試驗（通常為隨機、固定劑量之劑量－反應試驗）；可簡化國外樞紐設計；以跨區域試驗銜接者須有具說服力之區域結果（問答集 Q11） |
| 安全性銜接資料 | 偵測約 1% 發生率之事件通常需約 300 位病人；必要時執行獨立安全性試驗 |
| 銜接性試驗報告備查 | 完成後送備查；結果判讀原則（相似即可銜接、劑量調整須有依據、安全性不足需補、無法證實需確認性試驗） |
