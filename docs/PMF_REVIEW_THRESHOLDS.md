# 國外藥廠工廠資料（PMF）審查門檻

系統內建 11 種國外藥廠 GMP 申請類型：
- 10 種 PMF 書面審查：依產品類別 × 申請方式區分。
- 1 種「國外藥廠 GMP 實地查核申請」。

每種類型都只放該申請方式需要的表單與文件，每項附審查門檻。

> 本文件為法規資料整理，不構成正式法規意見。送件前請至 TFDA「[工廠資料(PMF)申請](https://www.fda.gov.tw/TC/siteListContent.aspx?sid=301&id=417)」確認最新版本。

## 怎麼選申請類型

| 產品類別 | 全套審查 | 簡化審查 |
|---------|---------|---------|
| 非無菌產品（含包裝作業） | `pmf_nonsterile_full` | `pmf_nonsterile_simplified` |
| 無菌產品 | `pmf_sterile_full` | `pmf_sterile_simplified` |
| ATMPs／生物產品／生物原料藥／血漿衍生產品 | `pmf_bio_full` | `pmf_bio_simplified` |

| 引用與其他 | 類型 |
|-----------|------|
| 非原 GMP 核准函持有者，申請**相同**劑型／品項 | `pmf_quote_same` |
| 原 GMP 核准函持有者，申請**新增**劑型／品項 | `pmf_quote_holder_new` |
| 非原 GMP 核准函持有者，申請**不同**劑型／品項 | `pmf_quote_nonholder_diff` |
| 擴建廠房 | `pmf_expansion` |
| 非 PIC/S 會員國境內藥廠（一律實地查廠） | `gmp_onsite_inspection` |

**確效替代**沒有另外分成獨立類型。全套與簡化（非無菌簡化除外）都同時列出兩項，二擇一：
- 「表C-5 確效及驗證作業」。
- 「確效替代三文件」。

沒採用的那一項標記「不適用」並寫明原因（例如「採確效替代」）。

## 每案必備（所有 PMF 類型）

- **表A 送審表與審查費**
  - 每案限單一廠址、最多 3 個劑型／品項／作業內容。
  - 無菌製備與最終滅菌、SVP 與 LVP 各算 1 種劑型。
  - 申請內容依「西藥製造許可及 GMP 核定項目與作業內容之藥品劑型分類原則」填寫。
- **表B 查檢表**：逐項勾選 Y／N／NA；廠名、廠址與當地最新 GMP 證明一致。
- **表B-3 原廠授權函**：正本或數位簽章；生物類申請要寫明品項、劑型及製程階段。
- **表B-5 SMF 最新版**：依 100.05.02 署授食字第1001100562號函〈製藥工廠基本資料製備說明〉。

## 表C-1 共通性資料（逐項建檔）

標 `*` 者為擴建廠房也要填寫的欄位。

| 項目 | 重點 |
|------|------|
| *1.1、*1.2 廠名、廠址 | 與官方證明一致；通訊地址不同時註明 |
| 1.3 簽證 | 見上表（併入表B-4 項目） |
| *1.4.1 申請內容與製程階段 | 生物類勾選 11 種產品類別（動物來源、過敏原、疫苗、單株抗體、基因治療、細胞治療等） |
| *1.4.2 特殊類別產品 | β-lactam、荷爾蒙、Cytotoxic／Cytostatic、放射性藥品等 |
| *1.4.3 全程或分段 | 分段生產或委外檢驗須分別說明；非無菌簡化附作業流程圖 |
| *1.4.4 生產區平面圖 | 秤量至包裝，含人物流、氣流／壓差、潔淨度；所有相關棟別都要附 |
| 1.5 國內已核准或引用之核准函 | 附影本或核准證明（依適用性） |
| 1.6 藥廠概況（*1.6.2 全廠平面圖） | 廠地、各棟各樓層用途、委受託活動及合約 |
| 1.7 出產國核准之作業項目 | 官方文件影本 |
| *1.8.1 全廠產品清單 | 依劑型列出所有類別產品、主成分與廠房 |
| *1.8.2 特殊產品 | 生產配置；共用者附依 QRM（含 HBEL-PDE／ADE）之交叉汙染評估、定期評估、清潔確效摘要。未生產者標「不適用」 |
| *1.8.3 兼製非人用產品 | 動物用藥、食品、化粧品、醫材等；共用者附交叉汙染評估，非人體可用動物用藥另附毒理風險評估與清潔確效。未兼製者標「不適用」 |

## 表C-2～C-5（本系統未逐欄建檔）

表C-2～C-5 以單一項目列入，門檻寫明依表逐欄填寫並附資料，以及 113 年研討會預告的修訂方向：
- C-2、C-3、C-5：依新版 PIC/S GMP Annex 1，納入品質風險管理（Annex 20）、汙染管制策略（CCS）、RABS／隔離裝置。
- C-4：依 Annex 2A（ATMPs）、Annex 2B（生物原料藥及產品）、Annex 14（血漿衍生藥品）架構。

需要逐欄檢核時，可依 115 年版表C-2～C-5 再擴充。

## 國外藥廠 GMP 實地查核申請（`gmp_onsite_inspection`）

依 113 年研討會〈國外藥廠 GMP 實地查核管理〉建立，共 12 項：

| 階段 | 項目 |
|------|------|
| 申請文件 | 申請公文；實地查核申請表（新申請限 2 劑型並列代表性產品）；查驗登記申請書影本或案號；原廠說明函正本；GMP 證明；近 5 年稽查清單；近 3 年回收批次清單 |
| 圖面與份數 | SMF 1 式 3 份；生產區圖示與空調、水系統概述 1 式 2 份 |
| 定期檢查（依適用性） | 輸入藥品許可證清冊、GMP 核備函授權清單 |
| 查廠安排與查後 | 代表性產品關鍵製程排程；繳費期限最長 1 個月；補件 60 天／30 天；查核後 30 天內發缺失報告；4 個月內申復 |
