# 新藥查驗登記（化學藥）審查門檻

> 彙整自 **115 年度新藥查驗登記說明會**（2026-09-02，醫藥品查驗中心 CDE；台北生技園區）之電子講義（v2，70 頁）與兩場演講逐字稿，並參考先前整理之「送件文件與常見缺失整理」。
> 系統內對應：申請類型「**新藥查驗登記（化學藥）**」（`new_drug_registration`，35 項），定義於 `config/regulatory_schemas.yaml`。
>
> **聲明**：講者均表明演講內容僅代表個人／CDE 觀點；凡涉及政策方向、法規解釋與適用，以衛生主管機關（TFDA）之公告、最新版 RTF 查檢表及個案諮詢意見為準。本文件為送件前自我查核工具，不構成法規意見。

## 一、如何使用審查門檻

- 每個檢查項目都附有「審查門檻」：**項目必須逐條達到門檻，才可標記為「已完成」**。在系統中把項目改為已完成時，會先列出門檻請你逐條確認。
- 標為「依適用性」（或門檻中有【適用】說明）的項目，只適用於部分申請類型或輸入藥品，請先判定是否適用。
- AI 文件分析會把這些門檻一併送給模型，逐條判斷文件是否達到，未達者列為缺口並指出是哪一條。
- 風險等級依各項 `risk_rules` 隨狀態自動判定：未完成的必要項目多為「高」，審查中多為「中」，完成為「低」。

## 二、課程核心訊息

1. **證據要完整，不能只附摘要**：製程確效、分析方法確效、可滲出物研究都要附完整計畫書與報告書；「只附摘要」是最常見的退件原因之一，輸入藥品尤其常見。
2. **全案一致**：申請表、CTD、CoA、DMF、GMP、CPP、仿單的品名、劑型、含量、配方、廠址、日期與規格必須彼此一致；不一致時要主動說明。
3. **規格要有依據**：檢驗項目要符合藥典個論／通則、ICH 與 TFDA 公告；放寬限度或免除檢驗項目都須提出合理性依據。
4. **非臨床缺失多半是「沒有轉譯」**：試驗通常都做了，但 finding、NOAEL、暴露倍數沒有整理成審查可引用的敘述，或沒有寫進仿單（6.1 懷孕、6.4 小兒、9 過量、10.3 臨床前安全性資料）。
5. **CMC 是最大宗**：114 年收案在結案時仍有的缺失，以成品管制（3.2.P.5）最多；美國 FDA CRL 分析中 CMC 缺失佔 67.4%。

## 三、法規架構、時程與送件格式

| 項目 | 重點 |
|---|---|
| 法源 | 《藥事法》第 39 條第 1 項：製造、輸入藥品應申請查驗登記，經核發許可證後始得製造或輸入。送件資料依《藥品查驗登記審查準則》：化學藥品附件二、三；生物藥品附件六、七；核醫放射性藥品附件十、十一。 |
| 審查重點公告 | TFDA 110 年修正公告各類藥品查驗登記審查重點。 |
| 審查天數 | 新成分新藥 360 天；非新成分新藥及生物相似性藥品：有臨床資料 300 天、無臨床資料 200 天。 |
| 加速機制 | 精簡審查、優先審查、加速核准、突破性治療、小兒或少數嚴重疾病藥品認定，可縮短至 240／180／120 天；**須在查驗登記申請前先向 TFDA 申請認定**。 |
| 國產新藥示範方案 | 115 年 5 月推出；對象為非罕藥且無專利、資料保護或銷售專屬權議題之國產新藥與國產生物相似性藥品；經專案輔導與送件前模組批次審查後，審查天數 100 天；實施至 116 年 12 月底。 |
| 審查流程 | RTF 檢核有重大缺失 → 廠商有 4 個月內**一次**補齊重送的機會；實質審查後補件期限 2 個月，可展延 1 個月；不准後 4 個月內可申覆。 |
| 送件格式 | CTD 格式（M1 行政、M2 摘要、M3 品質、M4 非臨床、M5 臨床）。新成分新藥自 101 年起適用 CTD；**115.01.01 起新藥全面 ExPress 線上送件、不再收紙本**；**預計 116.07.01 起新成分新藥及生物藥品全面採 eCTD**。 |

### 採用證明與國內臨床試驗要求（審查準則第 38-1～38-4 條）

| 採用證明張數 | 國內臨床試驗 | 上市後風險管理計畫（RMP） |
|---|---|---|
| 0 張 | 國內 Phase I ＋ 同步執行之 Phase III 樞紐試驗，或同步執行 Phase II 與 III | 強制 |
| 1 張 | Phase I、II、III 擇一 | 不強制 |
| 2 張以上 | 不強制，但須申請銜接性試驗評估（BSE） | 不強制 |

| 採用證明 | 新成分必附；張數決定國內臨床試驗要求（見上表）。 |
| BSE | 新成分新藥依準則第 22-1 條另案申請；免除函不代表療效與安全性已獲認可。 |

### Module 3 原料藥（3.2.S）

| 項目 | 關鍵門檻 |
|---|---|
| S.2.1 製造廠 | 各廠的製造、放行檢驗、安定性試驗、包裝職責都要列明。 |
| S.2.3 物料管制 | 起始物廠名廠址與 CoA；多來源須提供分來源批次分析；規格納入殘餘溶劑與元素不純物，或提出免除依據。 |
| S.2.5 製程確效 | 完整計畫書及報告書。 |
| S.3.2 不純物 | 結構鑑定圖譜；殘餘溶劑減免原則見下方；附亞硝胺風險評估。 |
| S.4.1 規格 | 與 CoA／DMF 一致；含水分、熾灼殘渣；含量訂上下限；不純物閾值依 ICH Q3A（見下方）。 |
| S.4.3 方法確效 | 完整報告；Range 涵蓋規格；評估 LOD／LOQ；準確度至少 3 個濃度、9 個測定值。 |
| S.5 標準品 | 藥典級附購買證明或照片；非藥典級附來源、批號、結構鑑定、標定程序與 CoA。 |
| S.7 安定性 | 足以支持再測試期與儲存條件。 |

**殘餘溶劑減免原則**（講義引用 EMA Annexes to CPMP/ICH/283/95）

| 情形 | 減免條件 |
|---|---|
| ICH Q3C Class 2 溶劑用於最終步驟之前的步驟 | 3 批量產規模或 6 批先導規模之中間體／原料藥批次分析結果 **< Q3C 限量 10%**，得減免 |
| Class 2 溶劑用於最終步驟（化學反應或結晶；研磨、微粒化不算最終步驟） | **不得減免**，須在原料藥規格中訂允收標準 |
| 溶劑中的 Class 1 污染物（如苯，常見於丙酮、甲醇、乙醇） | 3 批量產規模或 6 批先導規模結果 **< Q3C 限量 30%**，得減免 |

**原料藥不純物閾值**（ICH Q3A(R2)，每日最大劑量 ≤ 2 g）：報告閾值 0.05%；鑑定閾值 0.10% 或每日攝取 1.0 mg（取低者）；驗證閾值 0.15% 或每日攝取 1.0 mg（取低者）。超過鑑定閾值須鑑定結構，超過驗證閾值須有安全性資料；具異常毒性的不純物，閾值應更低。

| 項目 | 關鍵門檻 |
|---|---|

| P.5.3 方法確效 | 符合下方最小適用範圍；藥典方法（如微生物限量）須提供方法確認（verification）資料。 |
| P.5.5 不純物 | 亞硝胺評估涵蓋所有來源；元素不純物須敘明採用哪個 Q3D Option（見下方）。 |
| P.6 標準品 | 同原料藥。 |
| P.8 安定性 | 長期資料更新至最新；涵蓋半製品暫存、調製後、使用中安定性。 |
| 3.2.R.1 | 製造管制標準書或批次製造紀錄與 P.3 內容一致。 |

**分析方法確效最小適用範圍**（分析確效作業指導手冊）

| 檢驗項目 | 最小範圍 |
|---|---|
| 含量 | 試驗濃度之 80%–120% |
| 含量均一度 | 試驗濃度之 70%–130% |
| 溶離度 | 規定範圍之 ±20%；採三階段允收標準（S1 Q+5%、S2 Q−15%、S3 Q−25%）且 Q=80% 時，應涵蓋 **35%–105%** |
| 雜質 | 報告量至規格值之 120% |

**成品元素不純物（ICH Q3D）**：113.07.01 起不再適用中華藥典第九版 <2231> 重金屬檢測，改依 <2233>／<2235> 或 ICH Q3D 評估。完整風險評估須涵蓋原料藥、賦形劑、水、製程設備與容器封蓋系統。

| 評估方式 | 應檢附 |
|---|---|
| Component approach – Option 2b | 完整風險評估＋原料藥與賦形劑實測值，且成品評估結果 < 30% PDE → 原則上免附成品檢驗結果 |
| Component approach – Option 1／2a | 完整風險評估＋實測值 < 30% 最大允許濃度（MPC）→ 原則上免附成品檢驗結果 |
| 實測值不完整（數值取自文獻、網站） | 完整風險評估＋至少 1 批成品實測值 |
| Product approach – Option 3 | 風險評估（至少含成品與容器封蓋系統）＋ 3 批成品實測值 |

**亞硝胺高風險賦形劑**（講義列舉）：微晶纖維素、Hypromellose、Povidone、硬脂酸鎂、乳糖單水合物。

**成品降解產物閾值**：講義引用 ICH Q3A(R2)／Q3B(R2) 表格，但表格為圖片，未能擷取數值。逐字稿舉例：每日最大劑量 10 mg 時，鑑定閾值 20 µg、驗證閾值 0.5%；50 mg 時，鑑定閾值 0.2%、驗證閾值 200 µg。實際數值請依 ICH Q3B(R2) 原文查表（**待核對**）。

### 2021–2025 年查驗登記（CDE 專案管理組）

- 化學藥品約佔 65%，其中新成分新藥最多；輸入案件約佔 88%；ATC 分類以抗癌藥與免疫抑制劑最多。
- 不准案件的常見缺失：
  - CMC：成品與有效成分的規格、方法與 CoA；成品安定性
  - 藥毒理：藥理技術性資料不足
  - 藥動藥效：產品連結性資料不足
  - 臨床：臨床資料不足、試驗結果無法證實療效

### US FDA CRL 分析（講義「同場加映」，共 439 筆，cutoff 2026-06-16；僅供參考，非臺灣標準）

- 缺失類別：CMC 67.4%、臨床療效與安全性 19.1%、非臨床 12.1%、臨床藥理 6.6%。
- 非臨床缺失（可判讀 32 筆）：可滲出物／可萃出物 40.6%、雜質驗證 28.1%、基因毒性 15.6%、新賦形劑 12.5%；集中在 505(b)(2) 申請。
